### 2. Mock adatbázis

#### [NEW] `src/data/methods.json`
Minimum **8 módszer** kártya, mindegyik a következő mezőkkel:
- `id`, `name`, `summary`, `category` (Jégtörő / Levezetés / Projektmunka / Konfliktuskezelés)
- `subjects` (Humán / Reál / Művészet / Általános)
- `timeEstimate` (pl. "5-10 perc"), `groupSize` (pl. "4-6 fő"), `energy` (Alacsony / Közepes / Magas)
- `steps[]` – lépésről-lépésre útmutató
- `tools` – szükséges eszközök
- `psychologyLink` – kapcsolódó pszichológiai elv ID-ja
- `proTips`, `commonMistakes`

#### [NEW] `src/data/psychology.json`
Minimum **4 pszichológiai elv**:
- `id`, `name`, `summary`, `description`, `examples[]`
