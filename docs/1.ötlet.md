# 📚 Pedu – Projekt Fejlesztési Terv

## 🎯 1. Projekt Célja és Alapötlete
A **Pedu** egy tantárgyakon átívelő módszertani és pedagógiai-pszichológiai digitális tudástár tanároknak. 
A cél, hogy a pedagógusok ne csak száraz tantárgyi sablonokat kapjanak, hanem egy helyen férjenek hozzá a modern óravezetési módszerekhez és az azok mögött meghúzódó pszichológiai folyamatokhoz (pl. *Pygmalion-effektus / önbeteljesítő jóslat, Growth Mindset, kiégés megelőzés*). 

**Fő értékajánlat:** Segít abban, hogy a tanítás emberközpontú, inspiráló, azonnal alkalmazható és a tanár számára mentálisan is támogató legyen.

---

## 🛠️ 2. A Technológiai Vibe Stack

* **Alaprendszer:** React + Vite (gyors fejlődés, villámgyors prototípus-készítés)
* **Nyelv:** TypeScript vagy Modern JavaScript (ES6+)
* **Dizájn / Stílus:** Tailwind CSS
  * *Megjelenés:* Letisztult, modern, "tanár-barát" UI.
  * *Színvilág:* Megnyugtató, fókuszt segítő paletta (pl. pasztell kék, menta, pala szürke, meleg törtfehér háttér).
  * *Témák:* Teljes körű Világos / Sötét mód (Dark mode) támogatás.
* **Ikonok:** Lucide React (egységes, beszédes vizuális elemek).
* **Adatkezelés (Prototípus szinten):** 
  * Statikus, jól strukturált Mock JSON adatbázis a módszereknek és pszichológiai elveknek.
  * **LocalStorage** a felhasználói preferenciák (pl. "Kedvencek" lista, kiválasztott téma) perzisztens tárolására backend nélkül.

## 📐 3. Az App Szerkezeti Váza és Funkciói

### 3.1. Főoldal / Dashboard
* **Hero szekció:** Inspiráló üdvözlés + napi módszertani tipp.
* **Intelligens Keresősáv:** Keresés kulcsszavakra, módszerekre vagy problémákra (pl. *"figyelemhiány"*, *"csoportmunka"*).
* **Gyors Kategória Szűrők (Chips/Gombok):** 
  * Tantárgyi irányok: *Humán, Reál, Művészet/Készség, Általános*
  * Funkciók szerint: *Jégtörők, Levezetés, Projektmunka, Konfliktuskezelés*

### 3.2. Módszertani Adatbázis (Kártyás nézet)
Responzív kártyarács (Grid), ahol minden kártya egy azonnal bevethető gyakorlatot mutat be:
* **Kártya tartalma:** Módszer neve, rövid összefoglalója, ajánlott tantárgyak/korosztály.
* **Gyors-címkék (Badges):** Időigény (pl. *⏱️ 5-10 perc*), Csoportméret (pl. *👥 4-6 fő*), Energiaigény.
* **Interakció:** Kedvencnek jelölés ("Szív" ikon) + "Részletek" gomb.

### 3.3. Részletes Módszer Nézet (Modal vagy Dedikált nézet)
A kártyára kattintva megnyíló teljes útmutató:
* **Lépésről lépésre útmutató:** Hogyan vezesd le az órán (1., 2., 3. lépés).
* **Szükséges eszközök:** (pl. projektor, post-it, papír vagy eszközmentes).
* **🧠 A pszichológiai háttér:** Melyik pedagógiai-pszichológiai elvre épít a gyakorlat (kapcsolódási pont a Súgó kártyákhoz).
* **Tanári "Pro Tippek" & Gyakori hibák:** Mire érdemes figyelni a megvalósításkor.

### 3.4. Pszichológiai "Súgó" Kártyák (Tudástár)
Különálló szekció a mélyebb megértésért és a tanári mentálhigiénéért:
* Elméleti alapvetések érthetően, gyakorlati példákkal fűszerezve (*Pygmalion-effektus, Growth Mindset / Fejlődésfókuszú szemlélet, Kiégés (Burnout) felismerése és megelőzése, Pozitív megerősítés*).

### 3.5. Saját Gyűjtemény (Kedvencek megtekintése)
* A tanár által elmentett módszerek és elvek egybegyűjtve, hogy az óraszönetben vagy tervezéskor 1 kattintással elérhetőek legyenek.

## 🗺️ 4. Prototípus Fejlesztési Lépések (Roadmap)

1. **Fázis: Alapok és Adatstruktúra (Mock Data)**
   * Vite + React projekt inicializálása, Tailwind CSS beállítása.
   * `methods.json` és `psychology.json` létrehozása reális, minőségi mintaadatokkal (min. 8 módszer, 4 pszichológiai elv).
2. **Fázis: Layout és Komponensek Vizuális Felépítése**
   * Fejléc (Header), Navigáció, Hero keresősáv és Alap kártya komponensek megalkotása.
   * Pasztell színvilág és Dark/Light mód lefejlesztése.
3. **Fázis: Logika és Szűrési Rendszer**
   * Keresőmező bekötése, kategória gombok működtetése (aktív állapotok).
   * LocalStorage logika megírása a Kedvencek kezeléséhez.
4. **Fázis: Részletes nézet és Finomhangolás (Polish)**
   * Részletes nézet (Modal) kidolgozása.
   * Mikro-animációk, átmenetek és responzív ellenőrzés mobilra/tabletre.
